# Personal Portfolio Website

A personal portfolio website showcasing my skills, academic background, and software development projects as a BS Software Engineering student.

The website provides an overview of my technical skills, projects, education, and contact information in a clean and responsive design.

## About the Project

This portfolio was created to present my development journey, highlight the projects I have worked on, and provide a professional platform where recruiters, developers, and other visitors can learn more about my work.

## Features

* **Home Section:** Introduction, professional summary, and social links.
* **About Me:** Background, interests, and career goals.
* **Technical Skills:** Overview of programming languages, web technologies, concepts, and development tools.
* **Projects Showcase:** Project cards with images, descriptions, and relevant GitHub links.
* **Education:** Academic background and current degree information.
* **Resume Download:** Option to download my resume.
* **Contact Section:** Email and professional profile links.
* **Theme Toggle:** Switch between light and dark themes.
* **Responsive Layout:** Designed to adapt to different screen sizes.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git and GitHub

## Project Structure

* **index.html:** Contains the structure and content of the website.
* **style.css:** Handles the website's design, colors, layout, and responsiveness.
* **script.js:** Manages interactive features such as the theme toggle and navigation.
* **README.md:** Provides an overview of the project, its features, and technologies.
* **resume.docx:** Contains my resume for visitors to download.
* **images/:** Stores my profile picture and project screenshots used in the portfolio.

## How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Make sure the HTML, CSS, JavaScript, and image files are present.
3. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.
4. Explore the different sections of the portfolio.
